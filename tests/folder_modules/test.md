# folder_modules

**Validates (README §1, folders-are-modules):** three rules, one check
each — a folder aggregates its files' exported words (`using nested`);
a file sharing the folder's name takes the folder over and governs
what it exposes (`using governed`, self-contained); folder files stay
addressable by dotted path (`using governed.raw`). This case's
sub-folders ARE its subject.
